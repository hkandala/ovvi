---
title: "Add a machine"
description: "Settings ▸ Machines' add form"
---

Settings ▸ Machines is the one place that adds and edits machines (D54). The
machine button's "Add Machine…" and the new-window view's Add Machine open
Settings at Machines' add form; Settings' own "Add Machine…" opens the same
page ([Settings](/docs/ui/settings#machines)). Its fields:
- **Name:** how the machine menu lists the machine; the target when empty.
- **SSH target:** what `ssh` connects to, for example `user@devbox` or a
  host alias from `~/.ssh/config`. Add stays off while it is empty, starts
  with `-` or has a space, which the form says in red.
- **Icon:** a button with the icon; it opens a popover with about 140 SF
  Symbols in a grid (computers first, then networks, places and things) and a
  search by symbol name. A server rack for a new machine. The machine button
  shows only the icon, so the icon tells machines apart
  ([Machine button](/docs/ui/window#machine-button)).

Then:
- Add saves the machine and opens a new window on it with its `default`
  session; the other windows keep their pages, and Settings closes. After the
  new-window view's Add Machine, that window opens it instead while it is
  still open and empty (the last such window, whichever Add Machine adds). The window connects and runs the
  [checks on connect](/docs/machines#checks-on-connect).
- ssh's questions (an unknown host key, a password, a code) show in a glass
  dialog in that window ([The SSH connection](/docs/machines#the-ssh-connection)).
- The machine button's "Edit Machines…" opens Settings ▸ Machines, where each
  machine's page has the same fields, Save and Remove. Save keeps the edit;
  the machine's open windows show the new name and icon at once, and their
  next windows and pages use the new target (open sessions stay on the
  connection they have). Remove takes the machine off the list; its open
  windows stay until closed.
- The machine menu lists This Mac first, then the machine list.

Removing a machine never touches herdr on that machine.

How it works: [Machines and SSH](/docs/machines).
