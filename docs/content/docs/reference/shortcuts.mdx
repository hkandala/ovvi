This page lists the default shortcuts, in the groups of Settings ▸ Shortcuts. If you changed a shortcut, the menu bar,
the command palette and the Keyboard Shortcuts panel show your shortcut.

To see the most used shortcuts in the app, press ⌘/ (Help ▸ Keyboard Shortcuts). Press Esc or ⌘/ again to close the
panel.

Some actions have two shortcuts. Both run the action. The menu bar shows the first one.

## Keys that do not change

Settings ▸ Shortcuts does not list these keys:

- The keys of macOS: ⌘Q, ⌘H, ⌥⌘H, ⌘M, ⌘Z, ⇧⌘Z, ⌘X, ⌘C, ⌘V, ⌘A, ⌃⌘F (Enter Full Screen), ⌘\` and ⌃⌘Space. No action
  can take them.
- Return, Esc, Tab and the arrow keys in a list, a field or a dialog.
- In a chat: Return sends, ⇧Return starts a new line, and Esc stops the agent.
- Esc leaves the overview.
- In a Git card: ⌘↩ commits, ] and [ step through the changes, and `}` and `{` step through the files
  ([Files and Git](/docs/guide/files-and-git#diffs)).

## Change a shortcut

You change shortcuts in Settings ▸ Shortcuts. Each action shows its shortcuts at the right, one field each, stacked. An
action with no shortcut shows None.

To change a shortcut:

1. Open Ovvi ▸ Settings… (⌘,), then click Shortcuts.
2. Find the action. You can type its name or its keys in the search field.
3. Click the shortcut. The field says "Type shortcut…".
4. Press the new keys. They must include ⌘, ⌃ or ⌥.

To cancel, press Esc or click somewhere else.

### Add a second shortcut

1. Move the pointer over the action's row.
2. Click the + (Add Shortcut) before the last field. A new field shows under it.
3. Press the new keys.

### Remove a shortcut

1. Click the shortcut. The field says "Type shortcut…".
2. Click the × (Remove Shortcut) at the end of the field, or press ⌫.

### When another action has the keys

If another action already uses the keys, Ovvi asks first in a dialog, for example "⌘D is Split Right's key.":

- Swap, when you change a shortcut. The other action gets the shortcut that you replaced.
- Use Here, when you add a shortcut. The other action loses the keys.
- Cancel keeps all shortcuts as they were.

If the keys belong to macOS, the dialog says "macOS keeps it." and has only OK.

Two actions use the same keys without a problem when they work in different places. For example, Reload Page (⌘R)
works only over a browser card, and two plugins can use the same keys. A warning sign next to an action shows that an
action of Ovvi has its keys. Ovvi's action keeps the keys.

### Reset

A changed action shows a reset button before its first field. Click it to get the default shortcuts back. Reset All, at
the top of the page, resets every action.
