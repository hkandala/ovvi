Ovvi is a macOS app for [herdr](https://github.com/herdrdev/herdr). herdr is a terminal multiplexer for AI coding
agents: a program that keeps terminals running in sessions, spaces, tabs and panes, also when no window shows them.
Ovvi shows those terminals as live cards in a window, on This Mac and on remote machines that you reach with SSH.

herdr keeps everything: each space, tab, pane, terminal and agent. Ovvi draws it and lets you change it. When you
quit Ovvi, your terminals and agents keep running. When you open Ovvi again, it shows them where you left them.

![The Ovvi window with a sidebar of spaces and a tab of terminal cards](/images/window.png)

## What you can do

- Work in herdr's sessions, spaces, tabs and panes with the mouse and the keyboard: split, zoom, drag and float
  panes ([Basics](/docs/guide/basics)).
- Start Claude Code, Codex, Pi or OpenCode in a pane, see when each agent works, needs you or finishes, and talk to
  an agent in a chat view ([Agents](/docs/guide/agents)).
- Open a web page, a file explorer or a Git card beside your terminals ([Browser](/docs/guide/browser),
  [Files and Git](/docs/guide/files-and-git)).
- Add your own cards with plugins ([Plugins](/docs/plugins)).
- Let an agent open cards and send notifications with the `ovvi` command
  ([The ovvi command](/docs/reference/ovvi-command)).
- Do all of this on a remote machine over SSH, in the same way as on This Mac
  ([Setup](/docs/guide/setup#remote-machines)).

## Who it is for

Ovvi is for people who run coding agents in herdr, often several at once and on more than one machine. herdr's own
interface is a terminal interface for one machine at a time. Ovvi gives you a Mac window for each machine, with every
session, agent state and notification in one place.

## Requirements

- A Mac with Apple silicon and macOS 26 or later.
- herdr 0.9.3 or later on each machine that you use. This Mac needs herdr only for its own sessions. Ovvi can
  install herdr for you.
- On each remote machine: an SSH login, `sh` and Perl. Ovvi sends a small Perl script with each SSH connection
  ([How it works](/docs/reference/how-it-works#ssh-and-the-relay)).
- Node.js with npm, only to install, update or build plugins. The File Explorer and Git cards come with Ovvi.

## Install

Run this line in a terminal on your Mac:

```sh
curl -fsSL https://github.com/hkandala/ovvi/releases/latest/download/install.sh | sh
```

The script does these steps:

1. It makes sure that the Mac has Apple silicon and macOS 26 or later.
2. It downloads the newest release and makes sure that the download matches the release's checksums.
3. It puts `Ovvi.app` in `/Applications`, or in `~/Applications` when you cannot write to `/Applications`. An old
   copy is replaced where it is.
4. If Ovvi is running, it waits until you quit Ovvi (⌘Q). herdr keeps your sessions and agents while Ovvi is closed.
5. It asks before it installs the `ovvi` skill, which teaches Claude Code, Codex, Pi and OpenCode the `ovvi`
   command ([The skill](/docs/reference/ovvi-command#the-skill)).
6. If herdr is not installed, it asks before it installs herdr with herdr's own install command.
7. For each of Claude Code, Codex, Pi and OpenCode that is installed, it asks before it installs or updates herdr's
   integration for that agent. The integration tells herdr when the agent works or waits.
8. It opens Ovvi.

Run the script without `sudo`. To install one release, add its version after `sh`:

```sh
curl -fsSL https://github.com/hkandala/ovvi/releases/latest/download/install.sh | sh -s -- --version 0.1.0
```

You can also download `Ovvi-<version>.zip` from the [releases page](https://github.com/hkandala/ovvi/releases)
in a browser. Ovvi is not notarized, so macOS blocks the first open of a downloaded copy. To open it, go to System
Settings ▸ Privacy & Security and click Open Anyway. The install script needs no such step.

Next, read [Setup](/docs/guide/setup). It covers the first launch and how to add a remote machine.

### Build from source

To build Ovvi from its source, follow the README in the [repository](https://github.com/hkandala/ovvi). `make
install` builds your checkout as Ovvi Dev, a second app that runs beside Ovvi. Ovvi Dev has its own name, icon and
settings, and it gets no updates. To update it, run `git pull && make install` again.

## Updates

Ovvi checks for a new release once a day. When it finds one, each window shows the notice "Ovvi ‹version› is
available" at its bottom right. Ovvi never installs an update by itself.

1. Click Update… in the notice. To check now, choose Ovvi ▸ Check for Updates….
2. Read the release notes, then click Install Update.
3. Click Install and Relaunch when the download is ready.

herdr keeps every pane and agent running while Ovvi relaunches. To skip one release, click Skip This Version in step
2.

To turn off the daily check, turn off Check for updates automatically in Settings ▸ General. Check Now on the same
page checks at once ([Settings](/docs/reference/settings#general)). You can also run the install line again: it
replaces Ovvi with the newest release.

## Uninstall

1. Quit Ovvi.
2. Delete the app, its configuration folder, its logs and its settings:

   ```sh
   rm -rf /Applications/Ovvi.app ~/.config/ovvi ~/Library/Logs/Ovvi
   defaults delete dev.ovvi.app
   ```

   If Ovvi is in `~/Applications`, delete `~/Applications/Ovvi.app` instead.
3. If you installed the `ovvi` skill, delete its links:

   ```sh
   rm -f ~/.agents/skills/ovvi ~/.claude/skills/ovvi
   ```

`~/.config/ovvi` holds your plugins, also the plugins that you made with New Plugin. To keep a plugin, copy it out of
that folder first.

Uninstalling Ovvi does not remove herdr, and your sessions keep running. herdr's own docs say how to remove herdr.
To delete every file that Ovvi keeps, see [Reset Ovvi](/docs/reference/help#reset-ovvi).
