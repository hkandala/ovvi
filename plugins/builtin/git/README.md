# Git for Ovvi

A plugin for [Ovvi](https://ovvi.dev): a repository's changes and history in an Ovvi card. It shows the working
tree's diff (unified or side by side), the commit history and each commit's diff, and fetches, pulls and pushes.

## Install

Git comes with Ovvi, and Ovvi keeps it up to date. To install it again after removing it:

1. In Ovvi, open Settings ▸ Plugins (or Plugins… in the command palette, ⌘K).
2. Type `npm:@ovvi/git` and press Return.
3. Read the confirmation, then click Install.

Open it from a new pane's list (Git), or with Open Git in the command palette.
