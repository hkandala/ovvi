# File Explorer for Ovvi

A plugin for [Ovvi](https://ovvi.dev): browse files and folders, and view or edit a file, in an Ovvi card. It opens
folders, text and code (with find and replace), Markdown (rich text or source), images, PDFs and more.

## Install

File Explorer comes with Ovvi, and Ovvi keeps it up to date. To install it again after removing it:

1. In Ovvi, open Settings ▸ Plugins (or Plugins… in the command palette, ⌘K).
2. Type `npm:@ovvi/explorer` and press Return.
3. Read the confirmation, then click Install.

Open it from a new pane's list (File Explorer), or with Open File Explorer in the command palette.
